How the AQI Works

AQI is calculated using the EPA method based on PM2.5 and PM10. The index uses breakpoints: 0-50 Good, 51-100 Moderate, 101-150 Unhealthy for Sensitive Groups, 151-200 Unhealthy, 201-300 Very Unhealthy, 301+ Hazardous. CO₂ above 1000 ppm suggests ventilation needed; above 1500 ppm indicates critical levels.
